## Publicación en GitHub Pages
1. Descarga y descomprime este ZIP.
2. En tu repositorio `portafoliofp`, reemplaza la estructura anterior por el contenido de esta carpeta.
3. Sube y confirma todos los archivos y carpetas manteniendo sus rutas.
4. En GitHub Pages, conserva la configuración actual de publicación desde la rama/carpeta que ya utilizas.
5. Abre la URL del portafolio y prueba los cuatro enlaces de proyectos, el botón de regreso, el formulario y la versión móvil.

No cambies las rutas relativas ni muevas los archivos fuera de sus carpetas.
